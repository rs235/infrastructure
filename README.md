## General

This repository provisions my personal home infrastructure including a full Kubernetes cluster and services. Provisioned infrastructure is not split into standard environments like dev, test, prod because it would be highly impractical in a home environment. 
This repository does not manage the very base layer of my home environment which includes Proxmox, TrueNAS and OPNsense.
